# citation-check

Check each cited claim against what its source actually says.

## Steps
1. List every claim in the draft that has a citation (link, footnote or reference).
2. For each one, open the source (fetch the URL or read the file) and find the passage the claim relies on.
3. Mark each claim:
   - **Supported:** the source says it, quote the passage.
   - **Partly:** the source says something weaker or narrower. Quote it and show the difference.
   - **Not found:** nothing in the source supports it.
   - **Unreachable:** the source could not be opened.
4. Return a table: claim, verdict, quoted passage.

## Rules
- Quote the source exactly; never paraphrase it as if it were a quote.
- Do not rewrite the draft unless asked.
